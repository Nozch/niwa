ブランド画像の生成

OGP画像とfaviconの生成元。色と書体はサイト本体（src/styles/global.css の stationery テーマ）から 写した値で、絵柄を変えるときは下の PALETTE と drawOg / drawIcon を直す。
この環境にはSVG→PNGの変換ツールが無く、ブランドの書体 Klee One もOSに入っていないため、 Webフォントを読めるブラウザのcanvasで描くのが、サイトと同じ字形を出せる唯一の経路になっている。

作り直す手順: このファイルをブラウザで開き、下の5つのリンクからPNGを保存する。 og.png / apple-touch-icon.png / icon-192.png は public/ へ、 icon-16.png / icon-32.png は scripts/icon-sources/ へ置き、 最後に node scripts/make-favicon-ico.mjs で public/favicon.ico を作り直す。
16pxと32pxは favicon.ico の中身になるだけで単体では配信しないので、公開ディレクトリには置かない。
寸法を変えたときは src/layouts/BaseLayout.astro の OG_IMAGE の width / height も合わせる （ここがずれると共有カードの形が崩れる）。
